# RLINE Wave

Use this skill to create or update RLINE waves.

## Wave requirements

- Define a product-neutral kernel or migration goal.
- Identify affected crates and consumer repos.
- Break the wave into small pulses.
- Include validation expectations for every pulse.
- Record non-goals so RLINE does not absorb product-specific workflow logic.
