Abstract costs, explicit boundaries

This is an undirected graph workbench. You define the meaning of each non-negative edge cost. It does not establish geography, service feasibility, election fairness or downstream adoption.

Distances use native floating-point comparisons with absolute tolerance 1e-9. Topology metrics ignore weights. Boundary metrics collapse parallel node pairs and ignore loops; zero-volume conductance is reported as native zero and does not certify a good partition. Path counts are diagnostic only, especially with zero-cost cycles or tolerance ties.

1. Supply a graph

Interactive inspection requires JavaScript and WebAssembly. Input, source and artifact downloads remain available.

Use 1–64 node labels and up to 512 edges. Node references are zero-based indices. Edge IDs must be unique; weights range from 0 to 1e100. Selected indices and blocked edge IDs must be unique and declared. Unknown fields are rejected.
